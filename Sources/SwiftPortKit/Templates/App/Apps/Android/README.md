# Apps/Android — Phase 2

Kotlin + Jetpack Compose UI following Material Design 3, talking to `Core/`
through the Swift Android SDK + swift-java JNI bridge.

Not yet scaffolded. `swiftport init` creates this directory as a stub when
`android` is selected in `swiftport.toml`; the Gradle project, `.so` packaging
into `jniLibs/`, and Paparazzi/Roborazzi snapshot tests arrive in Phase 2.
